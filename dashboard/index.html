2
Host it anywhere

Options from easiest to most control:

  • Netlify Drop — drag the file to app.netlify.com/drop. Live in 30 seconds, free.
  • GitHub Pages — add to a repo, enable Pages. Good if you want version control.
  • Any static host — S3, Cloudflare Pages, Vercel, your own nginx. It's just a file.
  • Open locally — double-click it. Works for personal use, but the pre-connected bookmark URL won't transfer to other devices.
3
Customize it (optional)

Open the file in a text editor. At the top of the <script> section, you'll find a DASHBOARD_CONFIG block:

const DASHBOARD_CONFIG = { title: 'PoorJar', // browser tab + topbar accentColor: '#4AE3A0', // highlight color defaultDays: 7, // 7, 30, or 0 (all time) eventsPerPage: 25, // rows in events table };

Change the values, save, re-upload. Done.

4
Pre-connect it (skip the login screen)

Once connected, hit "Copy link" in the topbar. Bookmark it. That URL has your credentials encoded in the hash — paste it in the file to make it connect automatically on load:

// At the bottom of DASHBOARD_CONFIG, add: autoConnect: { url: 'https://YOUR_PROJECT.supabase.co', key: 'your-anon-key', }
